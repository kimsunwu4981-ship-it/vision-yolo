# 크레인 재해 영상 인식 문제 — 2026-11-17

이 문서는 원거리 CCTV 진단·수정 작업 기록이다. 사용자 지시에 따라 **기존 라벨 데이터만 학습에 사용**했다. 두 사용자 영상은 진단·회귀 검사 및 학습 데이터 중복 제외에만 사용하며, 프레임·배경·의사 라벨을 학습에 넣지 않았다. 현장 정답 인수나 정확도 100%를 주장하지 않는다.

## 확인한 원인

1. 다중 객체를 한 명으로 제한하는 코드가 원인은 아니었다. 기존 사람 모델이 추적 전에 사람 자체를 놓쳤다. 이 작업 시작 시 `크레인 재해.mp4` 1,092프레임 중 사람 박스가 있던 프레임은 28개였다. 기존 개발 이미지 평가가 높아도 이 영상의 원거리·상부 시점·가림에 일반화하지 못했다.
2. 640 입력에서는 원본 높이 약 40–115픽셀인 사람이 더 작아진다. 작은 crop/타일, 낮은 임계값, 더 높은 해상도만으로 해결되지 않았다. 큰 사람 모델과 약한 3×3 median 전처리의 조합은 같은 원본에서 실제 작업자들을 추가 검출했다. 원본의 강한 고주파 경계에 대한 민감성이 관측됐으며, 특정 촬영 필터나 편집 이력을 원인으로 단정하지 않는다.
3. 기존 학습 선택은 특정 근거리·옥상 장면에 편중됐다. `hat` 라벨은 일반 모자와 혼동될 수 있어 제외됐으나, 학습 표본 검토에서는 산업용 안전모도 다수 확인됐다. 이를 보강한 첫 context 후보만으로는 현장 문제가 해결되지 않았다. 추가 조사에서 D드라이브에 이미 보유한 별도의 안전모·맨머리, 조끼·일반 상의 COCO 라벨 압축파일을 찾아 학습 범위를 넓혔다.
4. 기존 보호구 상태 로직은 작은 사람 또는 얼굴/어깨/골반 좌표가 없는 사람을 판단불가로 처리했다. 검출 모델을 고쳐도 이 조건 때문에 직접 관측한 안전모 착용 증거가 무시될 수 있었다. 보호구 부재와 직접 검출한 착용/미착용 증거를 구분하도록 수정했다.

## 구현

- 기존 근거리 사람/PPE/pose 모델을 유지하고, 원본 너비 1,000 이상인 가로 영상의 작은 사람에 새 `person_detail` 모델을 보조 적용한다. 원본 좌표에서 median/median-flip 두 시야를 분석하고 flip을 한 번 복원한 뒤 중복을 제거한다. 영상 이름이나 수동 위치를 검출 조건으로 사용하지 않는다.
- 상세 사람 모델 하한을 .4로 분리해 낮은 점수의 설비 오검출이 추적을 통해 화면에 남는 것을 줄였다. 기존 근거리 모델의 약한 관측 추적은 유지한다. 이 설정은 진단 영상에서 조정했으므로 독립 test 성능으로 해석하지 않는다.
- PPE는 현재 프레임의 실제 사람 검출 crop에서 검사한다. crop 수와 microbatch를 제한하고, 좌표를 원본 픽셀로 한 번만 복원한다. crop 소유자는 처리 링크일 뿐 소속 정답이 아니므로 다른 작업자와 모호한 연결은 거부한다.
- 직접 검출한 `helmet`/`safety_vest`는 자세 좌표 없이도 착용 근거가 될 수 있다. 직접 검출한 `bare_head`/`bare_torso`는 높은 신뢰도·일대일 소속·시간 확인을 통과해야 미착용 근거가 된다. 양/음성 증거가 충돌하면 판단불가다.
- 머리/몸통 고정 비율로 표시 박스를 만들지 않는다. 신체 위치 비율은 다른 부위의 오검출을 거르는 연결 조건에만 쓰며, 실제 출력 박스는 모델 좌표다. 관측이 사라지면 과거 부위 박스를 재사용하지 않는다.
- 사람 크기·부위 관측에 의존하는 기존 보수적인 **부재 추론** 조건은 유지했다. 작은 사람에서 안전모를 못 찾았다는 이유만으로 미착용 처리하지 않는다.
- 자세 분석 자체는 높이 48픽셀부터 수행하고, 180픽셀 이하의 사람 crop에만 3×3 median 전처리를 적용한다. 가까운 사람의 입력 픽셀은 유지한다. 자세 모델·관절 신뢰도 기준은 그대로이며, 작은 사람의 몸통을 찾았다고 해서 90픽셀 미만의 보호구 부재를 확정하지 않는다.

## 재현

```powershell
python -m scripts.prepare_archive_states --version newversion
python -m scripts.audit_scale_manifests head-state-yolo26s-newversion vest-state-yolo26s-newversion
python -m scripts.train_archive_state --kind head --version newversion --epochs 12
python -m scripts.train_archive_state --kind vest --version newversion --epochs 10
python -m scripts.evaluate_archive_state head-state-yolo26s-newversion
python -m scripts.evaluate_archive_state vest-state-yolo26s-newversion
python -m scripts.make_detail_registry --head-state head-state-yolo26s-newversion --output outputs/new-candidate.json
python -m scripts.replay video.mp4 --registry outputs/new-candidate.json --no-zones --output outputs/new-replay
python -m scripts.summarize_replay outputs/new-replay
```

위 도구는 기존 run을 덮어쓰지 않는다. 사람 v8 모델 재학습은 `scripts.train_person_context`와 해당 provenance를 따른다. 공식 초기 가중치를 그대로 운영 모델로 등록하지 않는다.
